# Contributing to Phoenix OS

## Purpose

This document defines the contribution rules for Phoenix OS.

## Principles

- Keep documentation up to date.
- Respect the project architecture.
- Follow the business rules.
- Use clear and descriptive commit messages.
- Every major change must be documented.

## Commit Convention

docs: documentation changes

feat: new feature

fix: bug fix

refactor: code improvement

test: tests

chore: maintenance

## Philosophy

Process over outcome.

Protect the capital.

Build with discipline.
