# 6. Acceptance Criteria

Une User Story est terminée uniquement si :

- le développement est terminé ;
- la documentation est mise à jour ;
- les Business Rules sont respectées ;
- les tests sont validés ;
- la fonctionnalité apporte une valeur mesurable.

---

# 7. Product Vision Reminder

Phoenix OS n'est pas un journal de trading.

Phoenix OS est un système d'exploitation personnel destiné à piloter :

- le trading ;
- la discipline ;
- les performances ;
- le patrimoine ;
- la progression du trader.

Toutes les évolutions doivent servir cette vision.
