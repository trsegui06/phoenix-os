# 1. Executive Summary

Phoenix OS est un système d'exploitation personnel destiné à gérer l'ensemble du cycle de vie d'un trader et de son patrimoine.

Le système est conçu pour remplacer les multiples outils dispersés (journal de trading, tableaux Excel, notes, statistiques) par une plateforme unique permettant de piloter les décisions, mesurer les performances et améliorer continuellement les processus.

Phoenix OS est développé comme un produit logiciel évolutif.

---

# 2. Vision

Créer le meilleur système personnel de gestion du trading, du risque et du patrimoine.

Le système doit permettre à son utilisateur de prendre de meilleures décisions grâce aux données plutôt qu'aux émotions.

---

# 3. Mission

Transformer une activité de trading discrétionnaire en une activité gérée comme une entreprise.

---

# 4. Product Goals

## Court terme

- Construire une base de données fiable.
- Mesurer la discipline.
- Mesurer les performances.
- Documenter toutes les décisions.

## Moyen terme

- Automatiser les statistiques.
- Gérer plusieurs comptes Prop Firm.
- Optimiser les setups.

## Long terme

- Gérer le patrimoine.
- Suivre les investissements.
- Créer un cockpit financier personnel.

---

# 5. Non Goals

Phoenix OS n'a pas pour objectif :

- de prédire les marchés ;
- de fournir des signaux de trading ;
- de remplacer le jugement humain.

Le système accompagne la décision.

# 8. Functional Requirements

Le système doit permettre :

- d'enregistrer chaque trade ;
- de relier chaque trade à une session ;
- de relier chaque trade à un setup ;
- de calculer automatiquement les statistiques ;
- de mesurer la discipline ;
- de produire des revues hebdomadaires.

---

# 9. Non Functional Requirements

Le système doit être :

- simple ;
- rapide ;
- évolutif ;
- documenté ;
- versionné.

---

# 10. Data Model

Le cœur du système est constitué de six bases :

- Trades
- Sessions
- Setups
- Prop Firms
- Errors
- Objectives

Toutes les statistiques proviennent de ces bases.
