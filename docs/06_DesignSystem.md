# Purpose

Le Phoenix Design System définit l'identité visuelle de Phoenix OS.

Son objectif est de garantir une interface cohérente, simple et orientée vers la prise de décision.

Chaque composant graphique de l'application doit respecter ce document.

---

# Design Philosophy

Phoenix OS est conçu comme un cockpit.

Chaque élément affiché doit aider l'utilisateur à prendre une meilleure décision.

L'interface privilégie :

- la clarté ;
- la discipline ;
- le calme ;
- la concentration.
